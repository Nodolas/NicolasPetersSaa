# How to Start the Website

Live site: https://nodolas.github.io/NicolasPetersSaa/

## First-time setup (only needed once)
```
npm install
```

## Option 1 — Double-click (easiest)
Double-click `start.bat` in the project folder.
The site opens in your browser with live reload.

## Option 2 — Terminal
```
npm start
```
Run this inside the project folder. The site opens at http://127.0.0.1:8080.

If port 8080 is already in use, a server is probably still running from earlier. Open http://localhost:8080 directly, or close the old terminal window first.

## Option 3 — No Node.js at all
Open `index.html` directly in your browser.
There's no live reload, and you need an internet connection for the fonts and animation libraries.

## Publishing changes
Merging into the `main` branch on GitHub publishes the site automatically. See "Publishing" in `README.md`.
